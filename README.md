# Voice Tools Buddy

An evidence-led comparison of dictation tools, built as a self-contained static page.

## Current editorial order

1. **Superwhisper** — strongest evidence-backed all-rounder
2. **VoiceInk** — best privacy-and-value Mac pick
3. **Wispr Flow** — best cross-device polish
4. **Typeless** — best for no-edit prose
5. **Dictato** — best low-cost private pick
6. **MacWhisper** — best for transcription depth
7. **kivi** — best Hindi-English specialist
8. **Glaido** — most promising, least proven

The order is intentionally not a generic popularity list. It weights workflow fit (30%), privacy/control (25%), platform and language coverage (20%), value (15%), and evidence confidence (10%).

## Evidence boundary

- First-party product and pricing pages anchor platform, pricing, language, and privacy claims.
- The Talkify latency benchmark is a directional one-Mac test of 20 trials, not an accuracy or reliability leaderboard.
- Reddit search and comment threads were reviewed through the connected Composio Reddit account. They are usage signals, not a representative survey.
- Public X indexing was available only sparsely through web search; vendor posts and isolated user posts are linked but not treated as consensus.
- INR is primary in the interface. Reference rates checked 17 September 2026 UTC: `1 USD = ₹96.02`, `1 EUR = ₹110.71`.

## Included interactions

- Collapsible filters for platform, pricing shape, offline behavior, language coverage, and open source.
- Ranked list with a one-line explanation of why each tool sits where it does.
- Evidence matrix exposing workflow, privacy/control, reach, and value dimensions.
- Detail dialogs with verified pros, trade-offs, confidence, community signal, and source links.
- Shortlist tray for side-by-side comparison.

Open `index.html` directly in a browser; there is no build step or backend.
